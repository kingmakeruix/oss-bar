# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

- Preferred: [GitHub Security Advisories](https://github.com/kingmakeruix/oss-bar/security/advisories/new) (private report)
- Alternative: open a [regular issue](https://github.com/kingmakeruix/oss-bar/issues) only if the issue is not sensitive

Please include the affected version, steps to reproduce, and impact if known. We'll respond as soon as we can.

## Supported versions

Only the latest minor release is supported with security fixes.

| Version | Supported |
| ------- | --------- |
| latest `0.x` | ✅ |
| older minors | ❌ |
